================================================================================
6A — Sunucuyu kısıtlı veritabanı kullanıcısıyla çalıştırma
================================================================================
Öncesi: sunucu veritabanına "postgres" (tam yetkili) ile bağlanıyordu (.env: DB_USER=postgres) — Bulgular #5(b).
Yapılanlar (yönetici PowerShell):
  1. Taze yedek: scripts\backup\veritabani_yedekle.py -> tkys_20261127_140215_399200.dump
  2. .env'ye tam yetkili hesap DB_MIGRATION_USER / DB_MIGRATION_PASSWORD olarak da eklendi (parola ekrana yazılmadan).
  3. Önizleme: python scripts\uygulama_kullanicisi_olustur.py
       ÖNİZLEME: veritabanında hiçbir şey değiştirilmedi.
         Veritabanı            : tkys
         Yönetici kullanıcı    : postgres
         Oluşturulacak kullanıcı: tkys_uygulama (süper kullanıcı değil; tablo oluşturamaz/silemez)
  4. Oluşturma: python scripts\uygulama_kullanicisi_olustur.py --uygula
  5. .env: DB_USER=tkys_uygulama (DB_PASSWORD yeni parola); DB_MIGRATION_USER=postgres olduğu gibi kaldı.
     (Select-String ile doğrulandı: .env:9:DB_USER=tkys_uygulama  /  .env:39:DB_MIGRATION_USER=postgres)
  6. Sunucu yeniden başlatıldı (schtasks /End, port kapandı, schtasks /Run).
